# 🍽️ Don't Yuck My Yummm!!!

A simple recipe website developed using **HTML and CSS** as part of an academic project. The website showcases restaurant-style recipes with a clean and user-friendly interface, demonstrating the fundamentals of front-end web development.

---

## 📖 Project Overview

"Don't Yuck My Yummm!!!" is a static website that presents recipes in an organized and visually appealing format. It was created to practice HTML structure, CSS styling, and responsive webpage layout.

---

## ✨ Features

- 🏠 Simple homepage with navigation bar
- 🍝 Multiple recipe pages displayed on a single webpage
- 📝 Recipe descriptions, ingredients, and cooking methods
- 🖼️ Food images for better visual presentation
- 🎨 Custom styling using CSS
- 📱 Responsive layout with viewport support

---

## 🛠️ Technologies Used

- HTML5
- CSS3
